## Complete 16:9 Candidate Cover Prompt

```text
Create a complete 16:9 branded corporate article cover for a Hong Kong media article.

Article title: {{title}}
Topic: {{topic}}
Visual set direction: {{set_direction}}

Requirements:
- complete cover image, not just a background visual
- include uMaxDATA logo and SIP Social Intelligence Platform logo
- uMaxDATA logo and SIP logo must have equal visual height, vertical center alignment, and balanced brand weight like the reference cover
- include the full article title in accurate Traditional Chinese
- use Hong Kong local wording and typography style
- title color #004f5d
- light blue-gray left background
- right-side visual image area must be related to the title
- follow the reference 16:9 layout with diagonal translucent glass/structure transition
- if reference image is available, use https://files.umaxdata.com/af9bb15e-1e58-4380-a480-87afbf6f51be.PNG as the layout reference
- if no reference image is available, follow this layout description: left light blue-gray brand/title area 52%-55%, right visual area 45%-48%, logos at upper-left, bold #004f5d title below logos, diagonal translucent glass transition between text and visual areas
- realistic premium corporate editorial image
- Hong Kong / Greater Bay Area business context
- clearly related to the article topic
- logo and title must be complete, readable, no broken text, no missing words
- Chinese title must have sharp strokes, crisp edges, vivid color, and be absolutely readable
- no blurred typography, no distorted typography, no squashed text, no stretched text
- no fake extra text, no watermark, no distorted signage
- clean composition, professional lighting, high detail
- 4K high-resolution output

Negative prompt:
- simplified Chinese, fake text, gibberish, misspelled Traditional Chinese
- broken logo text, missing logo words, corrupted title characters
- blurry Chinese title, soft text edges, distorted title, stretched or squashed logos
- recognizable real person, celebrity likeness, public figure portrait
- sensitive political, religious, military, government, official-document or law-enforcement symbols
- sensitive cultural or religious architecture as the main visual focus
- violence, blood, disaster casualties, panic scene, hate symbol
- unauthorized logos, fake brand marks, distorted signage
- low resolution, blur, broken text, cropped logo, deformed people
```

## Full Cover Prompt 16:9

```text
Generate a complete 1280x720 corporate article cover using the provided reference cover, uMaxDATA logo, SIP logo, and generated topic visual.

Title: {{title}}
Subtitle: {{subtitle_optional}}

Layout:
- strictly match the reference cover's 16:9 composition
- left brand/title area occupies about 52%–55% of the canvas
- right visual image area occupies about 45%–48% of the canvas
- diagonal separation starts around x=735px at the top and x=655px at the bottom
- include reference-like translucent diagonal glass/structure transition lines between the text area and visual image area
- avoid a hard single-edge cut; use subtle layered semi-transparent light blue-gray polygons near the diagonal join
- light blue-gray left background
- title in #004f5d
- bold modern Chinese sans-serif typography matching the reference
- analyze the title meaning and split it into 2–3 natural semantic lines
- choose a reasonable font size according to title length and readability
- do not split fixed terms, brand names, event names, or noun phrases unnaturally
- if a subtitle exists, place it below the main title in smaller non-bold type
- preserve logo accuracy
- logos must remain complete, readable, uncropped, undistorted, with no broken text or missing words
- uMaxDATA logo and SIP logo must be the same visual height and aligned horizontally like the reference
- logo may be generated by image_generation, but must remain complete, readable, and faithful to the reference assets
- all non-brand text must be Traditional Chinese in Hong Kong local wording
- generate in 4K high resolution where supported
- export PNG and WebP versions
- no extra text

Negative prompt:
- simplified Chinese, fake characters, corrupted text, corrupted logo
- recognizable real-person portrait, celebrity face, public figure likeness
- sensitive cultural, religious, government or military buildings as the main focus
- political propaganda, violence, blood, hate symbols, disaster casualties
- unauthorized logos, misleading official symbols, official documents
```

## Full Cover Prompt Social Sizes

Generate a branded social media cover in {{ratio}} ratio using the same brand style as the reference.

Title: {{title}}
Subtitle: {{subtitle_optional}}

Requirements:

- light blue-gray background
- bold modern Chinese sans-serif typography

- title and subtitle must be complete, accurate, readable, Traditional Chinese, and suitable for Hong Kong wording
- analyze title semantics and use natural line breaks
- use fewer lines where possible while maintaining readability
- if subtitle exists, render it smaller and non-bold below the main title
- integrate the generated topic visual without simply cropping the 16:9 layout
- use the same selected candidate visual and same brand elements across all ratios
- independently adapt layout for each ratio; rebalance visual area, title line count, font size, spacing, and logo scale for the specific canvas
- social media title font size must be moderate, not oversized; preserve generous whitespace and visual balance
- split long titles by semantic meaning, punctuation, colon, dash, brand name, event name, and topic phrase
- do not split fixed terms or proper nouns such as The Big Bounce, 輿情溫度計, 事件分析
- use subtle translucent transition shapes between typography area and visual area where appropriate
- maintain strong readability on mobile
- no extra text
- logos must remain complete, readable, uncropped, undistorted, with no broken text or missing words
- generate in 4K high resolution where supported
- export PNG and WebP versions

Negative prompt:
- simplified Chinese, fake characters, corrupted text, corrupted logo
- recognizable real-person portrait, celebrity face, public figure likeness
- sensitive cultural, religious, government or military buildings as the main focus
- political propaganda, violence, blood, hate symbols, disaster casualties
- unauthorized logos, misleading official symbols, official documents
